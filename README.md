# বাঙালিয়ানা বাজার

বাংলাদেশের হাতে তৈরি জিনিসের বাজার। জামদানি শাড়ি, নকশি কাঁথা, মাটির কাজ,
বাঁশ আর বেতের জিনিস, পাটের ব্যাগ আরো অনেক কিছু। কারিগর নিজে দোকান খোলেন,
ক্রেতা সরাসরি তাঁর কাছ থেকে কেনেন। সাইটের সাজ হাটের মতো: কাঁথার সেলাই,
আলপনা, শামিয়ানা দেওয়া দোকান, আর ঝুড়ি মাথায় মামা।

## লেখার নিয়ম

এই সাইটের সব লেখা বাংলা। সহজ সরল বাংলা। ছোট ছোট বাক্য। কঠিন শব্দ নেই।
বাড়িয়ে বলা কথা নেই।

• সব লেখা বাংলা, সহজ সরল বাংলা।
• কোনো শব্দ মোটা নয়। সব লেখার ওজন ৪০০।
• কোনো লেখা বাঁকা নয়।
• শব্দ ভেঙে লাইন বদলায় না। সিএসএসে হাইফেন বন্ধ করা আছে।
• দাম বাংলা সংখ্যায় লেখা হয়। যেমন ৳৮,৫০০।
• ফন্ট: Baloo Da 2। এটা বাংলা হাতের লেখার মতো দেখতে, খুব জনপ্রিয় ফন্ট।
  গুগল ফন্টস থেকে আসে। শুধু ওজন ৪০০ লোড হয়। পড়তে সহজ রাখতে Hind Siliguri
  ফলব্যাক হিসেবে আছে। Kalpurush গুগল ফন্টসে নেই, তাই সেটা ব্যবহার করা হয়নি।

## ভেতরে কী আছে

• দোকান: Vite, React 19, TypeScript, Tailwind CSS 4, React Router।
• সার্ভার: Node আর Fastify, ফোল্ডার server। সাধারণ জাভাস্ক্রিপ্ট।
• তথ্য: DATABASE_URL দিলে PostgreSQL এ থাকে। না দিলে data/db.json ফাইলে থাকে,
  নিজের কম্পিউটারে কাজ করার জন্য।
• ঢোকা: মোবাইল নম্বর আর পাসওয়ার্ড। সার্ভার কুকিতে মনে রাখে।
• ঝুড়ি আর পছন্দের তালিকা ব্রাউজারে জমা থাকে।

পাতা:

• ক্রেতার জন্য: হোম, বাজার, পণ্যের পাতা, কারিগর, দোকান, ঝুড়ি (চার ধাপে অর্ডার),
  আমার পাতা, অর্ডার খুঁজুন, গল্প, আমাদের কথা, সাহায্য, নিয়ম, যোগাযোগ।
• বিক্রেতার জন্য: বিক্রেতা হোন, আমার দোকান (পণ্য, অর্ডার, পাওনা, দোকানের তথ্য)।
• মালিকের জন্য: /admin। অর্ডার, পণ্য, বিক্রেতা, ক্রেতা, গল্প, পাতা, বার্তা, মতামত,
  টাকা আর সাজানো। সাইটের লেখা, ডেলিভারির খরচ, WhatsApp নম্বর সব এখান থেকে বদলায়।

## পেমেন্ট: শুধু ক্যাশ অন ডেলিভারি

পণ্য হাতে পেয়ে টাকা দিতে হয়। কোনো অনলাইন পেমেন্ট নেই, তার কোডও নেই।
ডেলিভারির খরচ আর সময় অ্যাডমিনের সাজানো পাতা থেকে ঠিক হয়।
শুরুতে ঢাকায় ৳৬০, ঢাকার বাইরে ৳১২০।

## কীভাবে চালাবেন

```bash
pnpm install
pnpm dev:full    # এপিআই http://127.0.0.1:3001 আর দোকান http://localhost:5173
```

নিজের কম্পিউটারে অ্যাডমিন: নম্বর 01700000000, পাসওয়ার্ড admin123।
নতুন করে শুরু করতে data/db.json আর data/uploads মুছে দিন।

```bash
pnpm build      # tsc আর vite build, ফল dist ফোল্ডারে
pnpm lint
pnpm test:api   # সার্ভারের পরীক্ষা
```

## এপিআই

সব ঠিকানা আর তথ্যের গঠন docs/production-plan.md এ লেখা আছে। ভুল হলে সার্ভার
সবসময় { error: "সহজ বাংলা বাক্য" } ফেরত দেয়।

যাচাই: নাম কমপক্ষে ৩ অক্ষর। ফোন ০১ দিয়ে শুরু, ১১ সংখ্যা। ঠিকানা কমপক্ষে
৮ অক্ষর। পরিমাণ ১ থেকে ৯৯, স্টকের বেশি নয়। দাম সার্ভার নিজে হিসাব করে।

## ফোল্ডারের গঠন

• server: এপিআই। routes ফোল্ডারে পাতাভিত্তিক ঠিকানা, store.js এ তথ্য রাখা,
  auth.js এ ঢোকা, static.js নিজের সার্ভারে দোকান দেখায়।
• data/products.json, seed.json, content-seed.json: প্রথমবার চালু হলে এখান থেকে
  পণ্য, কারিগর, গল্প আর পাতা বসে।
• src/pages: সব পাতা। src/pages/admin: অ্যাডমিনের ভাগগুলো।
• src/components: হেডার, ফুটার, পণ্যের কার্ড, কাঁথার সেলাই, আলপনা, মেলার দোকান,
  মামার দৃশ্য। src/components/art: গল্পের পাতার বড় নকশা।
• src/libs/mascot: মামা। আলাদা লাইব্রেরি, যেকোনো পাতায় বসানো যায়।
• src/store: বাজারের তথ্য (market.tsx) আর ঝুড়ি (cart.tsx)।
• docs: পরিকল্পনা আর নিজের সার্ভারে তোলার নিয়ম। ROADMAP.md আর JOURNAL.md ও দেখুন।

## পণ্য কীভাবে যোগ করবেন

চালু সাইটে পণ্য যোগ হয় অ্যাডমিনের পণ্য পাতা থেকে, বা বিক্রেতার নিজের দোকান থেকে।

src/data/products.ts শুধু প্রথমবারের তালিকা। সেটা বদলালে pnpm sync:products
চালান। জেসন ফাইল হাতে বদলাবেন না।

## অনলাইনে তোলা

নিজের সার্ভারে (VPS): docs/deploy-vps.md দেখুন। এক কমান্ডে দোকান, এপিআই,
PostgreSQL আর HTTPS চালু হয়।

এখনকার ব্যবস্থা: দোকান Vercel এ, এপিআই Render এ।

• Render এ DATABASE_URL, JWT_SECRET, ADMIN_PHONE, ADMIN_PASSWORD বসাতে হবে।
  DATABASE_URL না দিলে সার্ভার নতুন করে চালু হলে অর্ডার আর অ্যাকাউন্ট মুছে যায়।
• Render এর ফ্রি সার্ভার ১৫ মিনিট চুপ থাকলে ঘুমায়। জাগতে এক মিনিট লাগতে পারে।
  তখনো দোকান খোলে, মামা অপেক্ষার ছবি দেখান।
